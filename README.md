# 🧱 Tetris Web

A modern Tetris game built with HTML5 Canvas and vanilla JavaScript.

## Features
- Classic Tetris gameplay with all 7 tetrominoes
- Progressive difficulty — speed increases every 10 lines
- Score system with level multipliers
- Next piece preview
- Local high score storage
- CSS animations and smooth rendering

## How to Play
1. Open `index.html` in your browser
2. Press **START** or hit **Space** to begin
3. Use arrow keys to move and rotate pieces
4. Clear lines to score points!

## Controls
| Key | Action |
|-----|--------|
| ← → | Move left/right |
| ↑ | Rotate |
| ↓ | Soft drop |
| Space | Hard drop |
| P | Pause |

## Tech Stack
- HTML5 Canvas
- Vanilla JavaScript (ES6+)
- CSS3 animations
